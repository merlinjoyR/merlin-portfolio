# Merlin Joy R - Personal Portfolio

## Project Overview

This is my personal portfolio website built using HTML, CSS, and JavaScript. It introduces my educational background, technical skills, projects, and contact information.

## Features

* Responsive design for desktop and mobile devices
* Home and About Me sections
* Education and Skills sections
* Projects and Certifications sections
* Contact details with email, LinkedIn, and GitHub links
* JavaScript-powered mobile navigation
* Automatic copyright year

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Git and GitHub
* GitHub Pages

## How to Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

## Deployment

The website is deployed using GitHub Pages.

**Live Website:** https://merlinjoyr.github.io/merlin-portfolio/
